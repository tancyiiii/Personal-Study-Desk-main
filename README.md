# Personal-Study-Desk
 # 多智能体 AI 学习助手
 
 一个强大、个性化的学习平台，由多个专门的 AI 智能体驱动。获取定制学习路线图、练习测验、AI 辅导和基于 RAG 的文档问答，让学习事半功倍！
 
 ## 功能特色
 
 ### 个性化学习分析
 - **学生画像**：AI 分析你的知识水平、目标和学习风格
 - **差距分析**：识别你需要学习的内容和前置知识
 - **定制推荐**：基于你的独特需求量身定制学习方法
 
 ### 智能学习路线图
 - **结构化学习路径**：将复杂主题分解为可管理的阶段
 - **时间优化**：根据你可用的学习时间调整计划
 - **里程碑追踪**：清晰的检查点以衡量进度
 - **灵活调度**：根据你的日程调整节奏
 
 ### 动态测验生成
 - **自适应难度**：题目匹配你的知识水平
 - **多种题型**：选择题、判断题、简答题、问题求解
 - **详细解释**：从正确答案和错误答案中学习
 - **自定义重点**：定位你想练习的特定主题
 
 ### AI 辅导
 - **全天候可用**：随时获得帮助
 - **个性化解释**：适应你的学习风格
 - **逐步指导**：分解复杂概念
 - **真实案例**：通过实际应用来理解
 
 ### 基于 RAG 的文档问答
 - **上传学习资料**：PDF、教科书、课堂笔记
 - **智能搜索**：即时找到相关信息
 - **上下文感知回答**：答案基于你的资料
 - **来源引用**：知道信息来自哪里
 
 ### 资源查找器
 - **精选资源**：AI 找到最好的学习材料
 - **质量筛选**：仅保留高质量、相关的资源
 - **匹配学习风格**：资源适合你的最佳学习方式
 
 ## 架构
 
 本项目使用多智能体架构，专门的 AI 智能体协同工作：
 
 ```
 study_agents.py          # 专门的 AI 智能体
 business.py              # 纯业务逻辑层（替代 agent_handler）
 rag_helper.py            # 基于文档学习的 RAG 功能
 config.py                # 配置管理
 prompts.yaml             # 智能体角色设定和提示词模板
 main_gui.py              # PySide6 原生桌面界面
business.py               # 纯业务逻辑层（替代 agent_handler）
 ```
 
 ### 智能体角色
 
 1. **学生分析智能体**：评估学习需求，识别差距，推荐方法
 2. **路线图创建智能体**：设计包含阶段和里程碑的个性化学习路径
 3. **测验生成智能体**：创建带解释的自适应评估
 4. **辅导智能体**：提供解释并回答问题
 5. **资源查找智能体**：搜索并推荐学习材料
 6. **RAG 辅导智能体**：使用上传的学习文档回答问题
 
 ## 使用的技术
 
 - **Phidata**：多智能体编排框架
 - **PySide6 (Qt6)**：原生桌面界面
 - **LangChain**：文档处理和 RAG
 - **ChromaDB**：RAG 向量数据库
 - **OpenAI/Groq**：LLM 提供商
 - **DuckDuckGo**：用于资源查找的网络搜索
 
 ## 最佳使用技巧
 
 1. **具体明确**：学习目标越详细，路线图越好
 2. **诚实评估**：准确评价你的知识水平以获得最佳推荐
 3. **上传资料**：使用 RAG 功能配合你的教科书和笔记，获取个性化帮助
 4. **定期测验**：经常测试自己以巩固学习
 5. **跟随路线图**：相信 AI 的结构化方法
 6. **多提问题**：大胆使用辅导功能——没有什么问题是愚蠢的！
 
 ## 学习风格详解
 
 AI 会根据你偏好的学习风格进行调整，以最大化学习效果。选择最能描述你学习方式的一项：
 
 ### 视觉型学习者
 **最佳学习方式**：通过观察和观看
 
 **特征**：
 - 更喜欢图表、图示和图像
 - 更容易记住面孔而非名字
 - 喜欢彩色编码的笔记和思维导图
 - 从观看演示中受益
 
 **推荐资源**：
 - 信息图表和流程图
 - 视频教程和演示
 - 思维导图和概念图
 - 可视化数据展示
 - 彩色编码的学习材料
 
 **学习建议**：
 - 使用荧光笔和颜色编码
 - 画图来理解概念
 - 观看视频讲解
 - 创建可视化摘要
 
 ---
 
 ### 听觉型学习者
 **最佳学习方式**：通过听和说
 
 **特征**：
 - 更喜欢口头指导
 - 记住听到的内容
 - 喜欢讨论和讲座
 - 经常边思考边说出来
 
 **推荐资源**：
 - 播客和音频讲座
 - 讨论论坛和学习小组
 - 口头解释和辩论
 - 教育歌曲或记忆法
 - 有声书和录音
 
 **学习建议**：
 - 大声朗读笔记
 - 录制并回听讲座
 - 与他人讨论主题
 - 使用口头重复
 - 大声解释概念
 
 ---
 
 ### 动觉型学习者
 **最佳学习方式**：通过动手和实践
 
 **特征**：
 - 通过做和实践来学习
 - 更喜欢身体活动和运动
 - 喜欢现实世界的应用
 - 需要亲自尝试
 
 **推荐资源**：
 - 交互式编程平台（针对编程）
 - 实验和模拟
 - 教育游戏和交互式工具
 - 动手项目和练习
 - 实物模型和操作工具
 
 **学习建议**：
 - 边学边做项目
 - 使用交互式模拟
 - 经常休息活动
 - 用真实示例练习
 - 创建实物模型或演示
 
 ---
 
 ### 阅读/写作型学习者
 **最佳学习方式**：通过阅读和写作
 
 **特征**：
 - 更喜欢书面信息
 - 喜欢做详细的笔记
 - 喜欢阅读教科书和文章
 - 通过写摘要来学习
 
 **推荐资源**：
 - 教科书和综合指南
 - 书面教程和文档
 - 笔记和摘要练习
 - 文章和研究论文
 - 列表、定义和词汇表
 
 **学习建议**：
 - 做大量笔记
 - 用自己的话重写信息
 - 创建书面摘要
 - 使用带文字内容的学习卡片
 - 反复阅读材料
 
 ---
 
 ### AI 如何使用你的学习风格
 
 当你选择学习风格后，AI 智能体会：
 
 1. **路线图创建器**：使用适合该风格的里程碑来构建学习路径
 2. **资源查找器**：优先推荐符合你偏好格式的资源
 3. **辅导智能体**：使用风格特定的技巧调整解释方式
 4. **测验生成器**：包含与你的学习偏好一致的题目
 
 **不确定自己属于哪种风格？** 试试**混合/多模态**方法，它结合了所有风格的元素！
 
 ## 故障排除
 
 ### ModuleNotFoundError: No module named 'X'
 **解决方案**：安装缺失的依赖
 ```bash
 pip install -r requirements.txt
 ```
 
 常见缺失模块及修复方法：
 - `phidata` → `pip install phidata`
 - `openai` → `pip install openai`
 - `chromadb` → `pip install chromadb`
 - `langchain_chroma` → `pip install langchain-chroma`
 - `langchain_openai` → `pip install langchain-openai`
 - `duckduckgo_search` → `pip install duckduckgo-search`
 
 ### "PySide6: module not found"
 **解决方案**：使用 Python 模块语法
 ```bash
 python main_gui.py
 ```
 
 或将 `~/.local/bin` 添加到 PATH：
 ```bash
 # PySide6 原生GUI无需PATH配置
 ```
 
 ### "No API key found" 或 API 错误
 **解决方案**：
 1. 确保 `.env` 文件存在于项目根目录
 2. 验证 API 密钥格式正确：
    - Groq 密钥以 `gsk_` 开头
    - OpenAI 密钥以 `sk-` 开头
 3. 检查密钥是否有效且已激活
 4. 对于 OpenAI：确保账户中有余额
 
 ### "Failed to load document"（RAG 功能）
 **解决方案**：
 - 确保 PDF 没有密码保护
 - 检查文件是否损坏
 - 尝试先转换为文本格式
 - 验证文件大小合理（建议 < 50MB）
 
 ### "Agent not responding" 或超时错误
 **解决方案**：
 - 检查网络连接
 - 验证 API 密钥是否有效
 - 尝试在应用设置中切换到不同的模型
 - 对于 Groq：检查 [status.groq.com](https://status.groq.com)
 - 对于 OpenAI：检查 [status.openai.com](https://status.openai.com)
 
 ### ChromaDB 错误
 **解决方案**：
 ```bash
 # 删除向量数据库并重启
 rm -rf chroma_db/
 python main_gui.py
 ```
 
 确保有写入权限：
 ```bash
 chmod -R 755 .
 ```
 
 ### 端口已被占用
 **解决方案**：
 ```bash
 # 启动原生桌面应用
 # PySide6 原生应用，直接关闭窗口即可
 
 # 或使用不同的端口
 python main_gui.py
 ```
